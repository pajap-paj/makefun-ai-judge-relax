A Python program that writes one short text to `/output/entry.txt`, written to
relax the AI judge reading it: a late-night house settling down — a fridge that
thinks better of humming, a moth at the porch light, the dark holding
everything still.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
